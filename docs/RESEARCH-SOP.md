# Research SOP (Team 02)

1. **Discover** using MLH, Devpost, official university/organizer sites.
2. **Verify** every important fact from a **primary source** (not directory copy-paste alone).
3. **Record** in the API with status `Needs Confirmation` until verified.
4. **Assign verifier** — a different team member reviews dates, eligibility, travel wording, links.
5. **Promote** to Verified only with evidence links and Medium/High confidence. The database rejects a Verified row that breaks this rule.
6. **Shortlist** with written practical rationale (not prize money alone). The database requires `shortlist_rationale`.
7. **Leave unknown** — use text like `Not publicly confirmed` or `Needs organizer confirmation`.

Never use AI or scrapers to invent eligibility, dates, or travel support.
