# Research SOP (Team 02)

1. **Discover** using MLH, Devpost, official university/organizer sites.
2. **Verify** every important fact from a **primary source** (not directory copy-paste alone).
3. **Record** the event with `operational_status` `needs_confirmation` until a teammate checks the primary sources.
4. **Assign verifier** — store `verifier_id` from `team_members`, and add each primary source as an `event_sources` row.
5. **Promote** with `operational_status` `verified_apply_now` or `verified_registration_upcoming`, and set `evidence_confidence` from the sources you actually checked.
6. **Shortlist** by writing `shortlist_entries.why_practical` and `queue_type` (`apply_now` or `prepare_before_opening`). Prize money alone is not a reason.
7. **Leave unknown** — use text like `Not publicly confirmed` or `Needs organizer confirmation`.

Never use AI or scrapers to invent eligibility, dates, or travel support.
